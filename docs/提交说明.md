# 原型设计作业提交说明

1. 博客正文使用 `拾光FindBack-原型设计作业-博客初版.md`。`assets/` 是配图；粘贴到 CSDN 后需上传图片并替换相对地址。`博客预览.html` 供本地阅读，不能当成已发布博客链接。
2. PPT 共 12 页，封面和第 11 页的绿色按钮可打开墨刀原型；第 11 页还有账号私有的实际系统链接。PPT 保留可编辑文字、5 张原生表格及每页备注。PDF 是同版视觉备用稿，包含原型超链接。
3. 墨刀原型采用 HTML 交互组件，正式演示页内可操作。使用模拟数据，刷新会重置。`prototype-html/拾光FindBack-完整交互原型.html` 是可离线打开的备份；八张编号 HTML 为静态设计参考页，不能单独当作完整交互原型。
4. `拾光FindBack-基础版源码与原型.zip` 包含前端、后端、数据库结构、测试、原型和云端部署源码；不包含 node_modules、Git 历史、会话数据库和部署凭据。最小本地运行只需要 Node.js 24+，解压后运行 `启动FindBack.cmd`。
5. 本次贡献比例已填写：Sun Zikun 13%、Luo Yuhan 11%、Zhou Shengdong 9%、Wu Junjia 7%，其余 10 人各 6%，合计 100%。本次讨论照片已补入博客第 8 节与 PPT 第 12 页；成员具体完成情况、个人感受和相互评价仍待补充。
6. 源码与最新版 PPT/PDF 收录在公共仓库 https://github.com/Zarvik188/FindBack-Gamers2-Prototype ，博客第 2 节已填写附件链接。尚未代发 CSDN 博客或提交课程作业页。墨刀分享面板显示“所有人”，实际系统演示站保持账号私有。

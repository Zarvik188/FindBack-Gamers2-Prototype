# 验收与实现说明

验证日期：2026-11-01。范围为教学演示基础版。

## 状态与权限

公开内容审核使用 `pending / approved / rejected`，物品流程使用 `open / claimed / returned / closed`（claimed 显示为“交接中”），认领使用 `pending / approved / rejected / cancelled`。审核公开内容不等于认领核验通过。拾主批准一条申请后物品进入交接；双方分别确认后才归还，单方不能结束流程。

访客仅可见已通过内容审核的信息；发布者可见本人待审核内容。发布者私密参考信息不进入公开列表，申请证据仅申请者和物品发布者可见。后台只负责公开内容审核。重复申请、跨用户审核或关闭、跨用户读取消息等由服务端拒绝。

## 架构与复用

浏览器通过相同的 `/api/*` HTTP 接口调用 `service.mjs`。本地数据库适配实现 prepare/bind/first/all/run/batch 接口；云端将同一业务模块绑定到 D1。SQL 均通过参数绑定执行。会话令牌只存哈希，密码使用带随机盐的 PBKDF2；Cookie 设置 HttpOnly、SameSite=Lax，并在 HTTPS 时设置 Secure。需要生产环境时还应增加校园认证、速率限制、日志监控和备份等实际部署工作。

## 当前限制

演示身份是刻意提供的角色切换入口；无需密码即可扮演示例发布者和管理员，因此不应存放真实个人材料。图片压缩和人工审核不保证完全自动识别敏感内容。没有图片相似度算法或校园身份背书，没有真实用户测试数据，也没有证明原 SRS 的性能与资源指标达标。

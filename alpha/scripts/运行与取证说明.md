# 运行、测试与取证

## 正常使用

在项目根目录用 Node.js 24+ 执行 `npm start`，访问 http://127.0.0.1:5180 。`npm test` 执行 26 项接口测试，`npm run check` 执行语法检查。后端运行及接口测试不需要额外 npm 依赖。

## 浏览器检查

需要可用的 Playwright 包与 Chromium 系浏览器。可以在独立工具目录安装 Playwright，并将该包绝对路径放入 FINDBACK_PLAYWRIGHT_MODULE，避免污染课程源码依赖。使用已安装 Edge 时指定 FINDBACK_BROWSER_EXECUTABLE。

```powershell
$env:FINDBACK_PLAYWRIGHT_MODULE='C:\你的工具目录\node_modules\playwright'
$env:FINDBACK_BROWSER_EXECUTABLE='C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
$env:FINDBACK_CAPTURE_DIR='C:\本次证据\2026-11-22'
node alpha/scripts/capture.cjs
```

脚本在 5187 端口启动临时服务，使用系统临时目录中新建的 SQLite 库，结束后停止该服务，不碰日常演示数据库。临时库保留在系统临时目录供排查。脚本固定为第一轮流程，日期由真实执行结果记录。后续日志需按本期修改补充新操作，不只重复首日画面。

## 进度与材料更新

`tasks.json` 保存任务和估算，`burnup.csv` 保存计划与实际检查点。未来实际值必须为空。更新进度时以已验收任务为准，保留当天状态快照和图。材料生成脚本 `build-materials.py` 是本次首日文稿生成器，会重建首日图和文稿；后续有手工修改时不要直接重跑覆盖。

本机测试与云端部署分别记录。未执行的环境在报告中写“未测”，不要以本地通过代替云端结论。
